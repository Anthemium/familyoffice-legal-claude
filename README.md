# FAMILY OFFICE LEGAL · by Markov Group — Claude edition

Прототип мини-платформы «Семейный офис под адвокатским управлением» (`familyoffice.legal`).
Версия Claude Code — параллельная вариантам из Antigravity, лежит отдельно, чтобы не пересекаться.

```
npm install
npm run dev          # http://localhost:3000/ru/
npm run build        # статический экспорт в out/ (GitHub Pages)
```

## Разделы

| Маршрут | Что это |
|---|---|
| `/{ru,en,hu}/` | Витрина (без интерактивных виджетов): статистика рынка, принцип, архитектура трёх уровней, 8 направлений практики, четыре модели офиса, юрисдикции и пороги, «гигиена тайны», анонс статей, контакты |
| `/…/journal/` | Аналитика: обзор из PDF, разбитый на 8 статей (`src/content/articles/{ru,en,hu}.ts`) |
| `/…/family/` | Кабинет семьи в банковской эргономике: семейный баланс, KPI, сообщение адвокату с проверкой «основной цели», «Щит 24/7», карта структуры, регуляторный календарь, совет семьи, поручения |
| `/…/studiolo/` | Студиоло — закрытый кабинет адвоката: вход по аппаратному ключу, дела, шаблоны на 3 языках, параллельный текст законов RU/EN/HU, матрица доступов, журнал, водяной знак |
| `/…/canon/` | Канон дизайна: палитра Pigmenta, типографика, правила работы с живописью |

## Концепция дизайна
**Pigmenta** — палитра по пигментам мастерских Ренессанса (ультрамарин, краплак, сусальное золото, тирский пурпур, смальта, умбра). Зелёных пигментов нет в принципе. Живопись — только подлинная, из открытых коллекций, в гравюрной обработке и с музейной этикеткой. Подробно — `.claude/skills/pigmenta-ui/SKILL.md`.

## Что взято из исследования (PDF)
- **Два контура и проверка основной цели** (§4: dual-purpose communications, Primary Purpose Test) — сообщение с коммерческим вопросом в правовом контуре подсвечивается, его предлагается разделить на два.
- **Запрет пересылки третьим лицам** (§4: third-party waiver) — в журнале Студиоло виден заблокированный форвард.
- **Три уровня владения** (§1) — схема на витрине и карта структуры в кабинете.
- **Статистика рынка** (8 000+ офисов, $1,6 млрд средний капитал, 800+ в DIFC, 63% с советами директоров) и **четыре модели** (§2) — на главной.
- Весь обзор §1–§8 — восемь статей раздела «Аналитика» на трёх языках.
- **Пороги юрисдикций** (§5–6: AMLR 25%/15%, FinIA, MAS 13O/13U, DIFC) и регуляторный календарь.

## Инфраструктура
- GitHub → `.github/workflows/pages.yml` собирает статическое демо для показа.
- Timeweb: `Dockerfile` (`FOL_TARGET=server`), `prisma/schema.prisma` для Managed PostgreSQL (RLS по семье, контуры A/B, неизменяемый журнал), S3 для документов (SSE-C, presigned на 5 минут), `.env.example`.

## Инструменты дизайна
- `npm run design:capture -- <url>` — скриншоты + токены любого сайта через установленный Chrome (`.claude/skills/design-capture`).
- `.mcp.json` — Playwright MCP для интерактивного разбора сайтов из Claude Code / Cursor.

## Примечания
- `next-intl` закреплён на 4.4.0: версии ≥ 4.5 тянут нативный `@swc/core`, который на этой машине падает на проверке прав `C:\`.
- Тексты законов в Студиоло — демонстрационные выдержки и рабочие переводы, перед боевым использованием сверить с официальными источниками.
- Цифры и семья «Вальден» — вымышленные демо-данные.
