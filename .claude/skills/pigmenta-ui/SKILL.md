# Pigmenta — канон интерфейса

Живая версия канона: страница `/[locale]/canon`. Токены: `src/app/globals.css` (`@theme`).

## Идея
Аристократизм через сдержанность: музейная гравюра, волосяная линия 1px, бумажный фон, много воздуха. Никаких вензелей, позолоченных рамок, градиентов «под золото».

## Палитра (зелёного нет вообще)
| Токен | Пигмент | Роль |
|---|---|---|
| `lapis` #23396B | ультрамарин | основной акцент, «норма/защищено» |
| `madder` #7A2433 | краплак | гриф адвокатской тайны, критичное, «Щит» |
| `gold` #A88449 | сусальное золото | тонкие акценты, «внимание» — не заливки |
| `tyrian` #5C3B61 | тирский пурпур | семья, governance |
| `smalt` #6E7C9B / `umber` #6B5644 | смальта / умбра | вторичные и нейтральные данные |
| `carta` / `vellum` / `ink` | белила, пергамент, сажа | фон, карточки, текст |
| `noct*` | — | тёмная тема Студиоло (кабинет адвоката) |

Статусы: ок → lapis, внимание → gold, критично → madder. Каждый цвет имеет `-soft` вариант для подложек.

## Типографика
- `font-serif` Cormorant Garamond — заголовки, цитаты, крупные суммы (lining-цифры уже включены).
- `font-sans` Manrope — интерфейс, таблицы, KPI.
- `font-mono` IBM Plex Mono — статьи законов, хэши, реквизиты, музейные этикетки.
Все три с кириллицей и венгерскими ő/ű. Не использовать шрифты без кириллицы (например, Plus Jakarta Sans).

## Живопись
- Только подлинные произведения из открытых коллекций (Wikimedia Commons, Rijksmuseum, Met Open Access), файлы в `public/art/`. Никакой генерации.
- Компонент `<Art>`: гравюрная обработка (`.art-engraving`), виньетка, подпись-этикетка через i18n.
- Предпочтение гравюрам (Пиранези) и фрагментам: руки, инструменты, архитектура.

## Дашборды
Эргономика банковских приложений: карточки `rounded-[var(--radius-card)]` (24px) на фоне `carta-2`, крупные цифры `font-semibold tabular-nums`, «истории» сверху, чипы-вкладки, нижняя навигация на телефоне. Отличие от типового банка — бумажный фон, засечные заголовки, пигменты.

## i18n
Любой видимый текст — в `messages/{ru,en,hu}.json`, все три файла обновляются вместе. Массивы читаются через `t.raw()`.
