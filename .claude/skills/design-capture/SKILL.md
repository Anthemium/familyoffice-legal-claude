# Design capture

1. Запусти из корня `claude-edition/`:
   ```
   npm run design:capture -- https://site.example
   ```
   Работает через установленный Chrome или Edge (`playwright-core`, браузеры не скачиваются).
2. Результат в `design-captures/<host>/` (папка в .gitignore):
   - `desktop.png`, `mobile.png` — полностраничные скриншоты; открой их через Read, чтобы увидеть композицию;
   - `tokens.json` — частотные цвета, фоны, шрифты, кегли, радиусы, тени, `:root`-переменные;
   - `report.md` — то же в читаемом виде.
3. Переводи найденное в токены Pigmenta (`src/app/globals.css`), а не копируй значения напрямую: референс даёт ритм и эргономику, палитра и типографика остаются нашими (см. skill `pigmenta-ui`).

Для интерактивного разбора (кликнуть, прокрутить, открыть меню) подключён Playwright MCP — см. `.mcp.json`.

Ограничения: не снимай закрытые разделы и страницы за логином; чужие изображения, тексты и логотипы — только для анализа, не для переноса в продукт.
